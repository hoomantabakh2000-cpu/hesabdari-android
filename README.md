# حسابینو

اپلیکیشن حسابداری و مدیریت انبار اندروید.

## وضعیت توسعه

### فاز ۱ — هسته و زیرساخت
- دیتابیس SQLite نسخه‌بندی‌شده
- Migration از ساختار اولیه بدون حذف اطلاعات
- دفتر تراکنش انبار به‌عنوان منبع اصلی موجودی
- تبدیل موجودی اولیه قدیمی به تراکنش افتتاحیه
- محاسبه بهای تمام‌شده با میانگین موزون
- جلوگیری از موجودی منفی در حالت عادی
- تست خودکار سناریوهای اصلی انبار و بهای تمام‌شده
- زیرساخت پشتیبان‌گیری و بازیابی دیتابیس
- ذخیره مبالغ به‌صورت Rial در هسته برای جلوگیری از خطای اعشاری

اطلاعات نمونه داخل برنامه قرار نمی‌گیرد؛ سناریوهای تست فقط در تست‌های خودکار اجرا می‌شوند.

بعد از تثبیت این فاز، توسعه فرم‌ها و عملیات واقعی خرید، فروش، طرف‌حساب و دریافت/پرداخت روی همین هسته انجام می‌شود.
